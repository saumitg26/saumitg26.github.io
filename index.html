TriageAI Healthcare AI · VTHacks 14
View Repository ↗

Emergency rooms get overwhelmed, and nurses often have under two minutes to assess acuity. We built TriageAI to capture vital signs contact-free using Presage camera feeds, calculate explainable ESI priority rankings with Gemini, and maintain a live queue with clinician override safeguards.

Built with React · FastAPI · PostgreSQL · Gemini AI · Presage SDK
Behind the build +
Rather than treating AI triage as a black box, the system structures vital estimates and patient symptoms into discrete clinical criteria. Gemini outputs structured justifications that doctors can inspect and override in one click before queue assignment.
MissionPay Guard 🏆 4th Place Global · AWS Maximus Hackathon
View Repository ↗

Our team built an automated pre-disbursement payment screening pipeline for public-sector programs. It intercepts disbursements, runs multi-variable fraud checks against ingested documentation, and routes flagged anomalies to a human review workspace before state funds leave the treasury.

Built with AWS Lambda · Step Functions · DynamoDB · Python · TypeScript
Behind the build +
Orchestrated via AWS Step Functions state machines. Each payment intake triggers concurrent document parsing and anomaly detection workers. High-confidence transactions pass cleanly; edge cases trigger hold states in DynamoDB with an immutable audit trail.
PhishLens Browser Security · OpenAI Build Week
View Repository ↗

Most anti-phishing extensions flash an unexplained red block page that users routinely ignore. I built PhishLens to actively parse form targets, brand impersonation cues, and suspicious DOM structures in real time—delivering an evidence-backed score explaining exactly why a link is risky.

Built with TypeScript · Chrome Extension API · Threat Intelligence · DOM Heuristics
Behind the build +
Engineered under Chrome's strict Manifest V3 service-worker constraints. Combines lightweight local threat signatures with heuristic analysis of login inputs and form submission targets to keep evaluation under 50ms without degrading page rendering.
CyberSurfaceMapper Security Reconnaissance
View Repository ↗

An automated reconnaissance dashboard written in Python to evaluate the exposure of public domains. Pairs non-intrusive HTTP security header auditing (CSP, HSTS, X-Frame) with multi-threaded port probing to provide a clear, actionable posture summary.

Built with Python · Streamlit · Network Sockets · Security Auditing
Behind the build +
Built to replace fragmented CLI lookups with an integrated interface. Uses asynchronous socket connections with strict timeouts to scan common service ports without hanging, then correlates findings with missing defensive headers to score risk.
PatriotGo Campus Mobility · PatriotHacks
View Repository ↗

George Mason has a huge commuter population with parking bottlenecks. We built PatriotGo during PatriotHacks—a campus ridesharing app with verified GMU university authentication, live ride posts, eco-tracking, and real-time student messaging.

Built with React Native · Expo · Supabase · Realtime DB
